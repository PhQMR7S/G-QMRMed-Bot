# GQMRMed Telegram Premium Emoji Kit

هذا المجلد مخصص لهوية الـTelegram Premium/Custom Emoji الخاصة بـGQMRMed.

## ما الذي سترسله لاحقاً؟

أرسل إلى البوت مجموعة الـCustom Emoji التي تريد اعتمادها، ويفضل واحدة لكل وظيفة:

- `brand` — هوية GQMRMed
- `medical` — طبي/سريري
- `create` — إنشاء تصميم
- `plans` — الخطط والاشتراكات
- `research` — البحث والتحقق
- `ai` — الذكاء الاصطناعي/تركيب المحتوى
- `design` — التصميم والإخراج
- `success` — نجاح العملية
- `warning` — تنبيه
- `support` — الدعم
- `free` — الخطة المجانية
- `plus` — PLUS
- `pro` — PRO

## مهم

Custom Emoji في Telegram ليست ملفات PNG عادية يتم وضعها داخل الرسالة. الاستخدام الاحترافي يعتمد على `custom_emoji_id` الذي تمنحه Telegram. لذلك لن نضع IDs عشوائية في الكود.

بعد إرسال الـPremium Custom Emoji، يتم اعتماد الـIDs الصحيحة وربط كل ID بالمعنى المناسب، ثم تستخدم الواجهة الـPremium Emoji في الرسائل التي تناسبها فقط.

أزرار Inline Keyboard ستبقى نصية وواضحة؛ لا نضع Premium Emoji عشوائياً داخل أسماء الأزرار.

## معيار الاستخدام

- لا نستخدم Emoji مزخرفاً بلا معنى.
- لكل وظيفة Emoji دلالي ثابت.
- لا نخلط عشرات الرموز في رسالة واحدة.
- الأولوية للوضوح الطبي والهوية البصرية الراقية.
